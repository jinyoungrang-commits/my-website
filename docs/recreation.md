# 캡처를 기준으로 재구성한 내용

이 문서는 이후 수정할 때 참고할 수 있도록 제공된 화면의 구조와 재현 결정을 기록합니다. 원본 소스에 접근하지 않고 전달받은 캡처를 분석했습니다.

## 디자인

- 흰 배경, 거의 검정에 가까운 본문 글자, 차분한 올리브색 보조 문구.
- 주 강조색 `#c1f582`, 카드 배경은 매우 옅은 회녹색, 가는 녹회색 테두리.
- 소개 페이지의 최대 본문 폭 1480px, 나머지 소개 섹션·실험실 바깥 폭 1332px, 팀방 중심 콘텐츠 833px.
- 소개 페이지 대제목 100px, 섹션 제목 58px, 실험실 제목 54~56px, 카드 제목 25~26px. 좁은 화면에서는 자동 축소합니다.
- 둥근 알약 모양의 주요 버튼, 20~25px 모서리의 카드, 여유 있는 세로 간격.
- 로고는 사용자가 보내준 이미지와 동일한 원본 사이트의 `dagachi-logo.jpg`를 내려받아 그대로 사용합니다. 상단·하단·소개 영역 및 브라우저 아이콘에서 같은 원본 파일을 참조합니다.

## 화면과 주소

| 캡처의 흐름                                    | 구현 화면                         |
| ---------------------------------------------- | --------------------------------- |
| 1~5: 소개·문제·기록/확인/근거·이름의 의미·시작 | `/`                               |
| 6~7: 실험실·이미지 선택·과제 설명·예시 체험    | `/lab`                            |
| 8~9: 팀원·교수님 선택 및 코드 입력             | `/lab/join`                       |
| 10~12: 예시 과제 3주 일정·마감일·이름·동의     | `/lab/plan`                       |
| 13~14: 팀방 준비·초대·역할 선호·대기           | 팀방의 오늘 우리 팀, 역할 배정 전 |
| 15~19: 할 일·나침반·진도·회의·달력·일정 입력   | 팀방의 오늘 우리 팀, 역할 배정 후 |
| 20: 활동 피드·활동 입력                        | 팀방의 활동 기록                  |
| 21: 팀원 카드·개인 정보 변경                   | 팀방의 팀원과 역할                |
| 22: 상호 평가 결과·평가 입력                   | 팀방의 상호 평가                  |
| 23: 팀원·교수님 초대 코드와 링크               | 팀방의 초대                       |

팀방 주소는 `/lab/team/:teamId`이며 `?tab=activity`, `?tab=members`, `?tab=reviews`, `?tab=invite`로 탭을 직접 열 수 있습니다. 브라우저에 참여 정보가 없으면 초대 코드로 입장해야 합니다.

## 실제 동작하는 기능

팀방 생성, 서버 저장, 다른 브라우저 참여, 선호 저장, 규칙에 따른 배정, 담당자·날짜 수정, 할 일 추가·상태 변경·완료 취소, 활동과 근거 링크 저장, 프로필 수정, 상호 평가, 교수님 열람 권한, 초대 코드·링크 복사, 월별 달력·날짜별 일정, 다음 회의 저장, 브라우저에서 팀방 재입장.

팀방은 8초마다 서버 변경을 확인하며 새로고침 버튼으로 즉시 가져올 수 있습니다. 진행률은 등록된 할 일의 완료 비율이며 기여도를 평가하는 점수가 아닙니다.

사용자의 무료 호스팅 요청에 따라 별도의 GitHub Pages 빌드를 제공합니다. 이 빌드에서는 서버 대신 현재 브라우저에만 팀방 체험 데이터를 저장하며 상단에 저장 범위를 안내합니다. 사전 신청은 별도로 FormSubmit을 통해 운영자 이메일로 전달합니다. 다른 기기 공동 저장과 문의 양식 접수는 지원하지 않습니다. 기본 Node 서버판의 공동 저장 기능과 공개판의 브라우저 체험 기능을 구분하세요.

## 캡처에 없거나 원본 연동이 필요한 영역

- 새 팀 만들기·상호 평가 작성·문의·개인정보 창·모바일 화면은 캡처의 디자인 체계를 따라 구성했습니다.
- AI 과제 분석은 원본의 준비 중 상태를 유지합니다. 외부 AI API는 사용하지 않습니다.
- 기존 서버 데이터·계정·배포 주소를 가져오지 않습니다. 새 서비스는 별도의 데이터베이스를 사용합니다.
- 캡처의 이름·코드는 화면 상태의 예시이므로 실제 팀방을 만들 때 사용자가 이름을 입력하고 새 코드를 발급합니다.
- 예시 마감일은 캡처의 `2026-11-06`을 사용하며 변경할 수 있습니다. 남은 날짜와 달력은 한국 시간 기준의 실제 날짜로 계산합니다.
